02 / current index

what we are building now.

  1. 01accompany

    cissa goes with you. cupboard brings your digital life home. two companions being developed around useful context, open systems, and data that belongs to you.

    hardware / software / in development

    accompany.tsc.hk ↗
  2. 02moonshine

    a bun-first web framework that starts with signals. routing, rendering, and server behavior are separate pieces you add as needed. its crepuscularity adapter connects .crepus templates to the web; moonshine also powers accompany’s site.

    typescript / bun / tschk

    moonshine.tsc.hk ↗
  3. 03crepuscularity

    a systems ui toolkit built around a compact template language. shared interface definitions reach desktop, terminal, web, and embedded surfaces. a rust parser, view ir, and hot reload keep the work connected across targets.

    rust / ui toolkit / tschk

    crepuscularity.tsc.hk ↗
  4. 04inauguration

    a compiler toolchain for bringing different languages into one shared intermediate representation. native compilation, jit execution, and a place for libraries from different ecosystems to meet.

    compiler / core ir / tschk

    inauguration.tsc.hk ↗
  5. 05alpenglow

    a minimal linux distribution exploring how little an operating system needs. musl, dinit, and oil packages form the foundation; desktop and graphical work remain experimental.

    linux / systems research / testing only

    alpenglow.tsc.hk ↗
  6. 06space

    what if the compiler helped define the operating system? space explores components, capabilities and execution graphs, from the .in language through inauguration to a nanokernel.

    capability-native os / research / tschk

    space.tsc.hk ↗
  7. 07telekinesis

    an ai coding agent built in rust, with a command line and terminal interface. rotary provides the agent loop, tools and sessions; crepuscularity provides the tui.

    agent / rust / tschk

    explore telekinesis ↗
  8. 08equilibrium

    automatic c ffi generation for c-compiling languages. less glue between ecosystems, with related projects eqswift and eqts connecting rust to swift and javascript runtimes.

    language interop / in development / tschk

    explore equilibrium ↗
